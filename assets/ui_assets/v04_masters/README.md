# V04 staged visual masters

These twelve images are the Stage 1 master set for BCM-M12 V04. They are intentionally stored outside the existing runtime asset tree so the owner and independent auditor can review the art direction before any 398-asset derivation/export work is authorized.

## Generation method

Each master was generated as an original raster illustration with the Codex image-generation capability using prompts grounded in the two immutable repository style-reference boards:

- `../source/style_reference_board_remediation_v01.png`
- `../source/style_reference_board.png`

No Pillow or procedural primitive art was used to generate the masters. Pillow was used only for the required technical contact-sheet composition. The source masters are portrait PNGs at `941 x 1672` pixels, preserving a consistent 9:16 mobile composition. `CONTACT_SHEET_V04.png` is a review-only contact sheet at `1200 x 1806` pixels.

## Stage boundary and protected content

This folder does not replace or overwrite existing runtime assets. No current runtime asset, canonical logo, table geometry/mask, reference board, gameplay logic, persistence logic, or M12 V02 controller logic was changed. No table skin is included in V04 Stage 1; any later table work must use the frozen table geometry contract exactly.

The complete 398-asset derivation/export stage is intentionally deferred until independent ChatGPT and owner visual approval of these masters.
